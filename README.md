# Proyecto-LMS

Un **Sistema de Gestión de Aprendizaje (LMS)** desarrollado como proyecto final de curso.

---

## Español

### Descripción del Proyecto
Este proyecto es un Sistema de Gestión de Aprendizaje (LMS) full-stack diseñado para administrar cursos y contenido educativo. Está construido en JavaScript utilizando **Node.js** con **Express** en el backend, **MongoDB** como base de datos y **Vite.js** para el frontend.

### Desarrollo y Aprendizaje
* **Backend:** Desarrollado completamente desde cero a mano por mí, enfocándome en la arquitectura, rutas y manejo de datos.
* **Frontend:** Desarrollado con asistencia de Inteligencia Artificial para acelerar la maquetación y profundizar en el aprendizaje de **Vite.js**, compensando un perfil orientado principalmente al desarrollo backend.

---

## English

### Project Overview
A full-stack Learning Management System (LMS) designed to host and manage educational content. Built with JavaScript using **Node.js** with **Express** on the backend, **MongoDB** for data persistence, and **Vite.js** for the frontend.

### Development Highlights
* **Backend:** Hand-coded entirely by me from scratch, focusing on core logic, routing, and database management.
* **Frontend:** Built alongside AI assistance to streamline component creation and accelerate hands-on learning with **Vite.js**, supplementing a backend-heavy skillset.
